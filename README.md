## About the Project

Secret Agent Hacker Terminal is an interactive, Matrix-inspired web application built using HTML, CSS, and JavaScript. It features a retro hacker interface with neon-green effects, animations, simulated hacking operations, and a hidden cipher mini-game.

This project was created as part of **Unit 3: AI Applications (CO3-P)** for the AI Coding Lab assignment.

## Features

- **Matrix-Style Animation:** Falling code effects with a dark terminal theme.
- **Network Scanner:** Simulates a network scan with animated progress.
- **File Decryption:** Runs a fictional file-decryption simulation.
- **Initiate Hack:** Displays an interactive simulated hacking operation.
- **Cipher Mini-Game:** Solve a secret code challenge.
- **Sound Effects:** Optional retro sounds with a mute toggle.
- **Responsive Design:** Works on desktop and mobile screens.

## How to Use

1. Open the live app using the link above.
2. Explore the terminal interface.
3. Click the operation buttons to run the simulations.
4. Discover and play the hidden cipher mini-game.
5. Use the sound toggle to enable or mute sound effects.
